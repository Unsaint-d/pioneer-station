# Pioneer Station

**Status**: Alpha
**Version**: 0.0.0 (Work in Progress)

## 📖 О проекте

**Pioneer Station** — это наземная станция управления (Ground Control System, GCS) для автономных беспилотных летательных аппаратов (БПЛА) серии **Geoscan Pioneer**.

Проект разработан как часть комплексной системы для **поисково-спасательных и охранных мероприятий**, где дроны используют нейросети для обнаружения людей. Pioneer Station решает задачу **планирования и управления полётом**: от создания маршрута в визуальном редакторе до загрузки задания на борт.

Также система может использоваться как самостоятельный инструмент для обучения пилотированию, программированию дронов и отладки миссий.

---

## 🚀 Ключевые возможности

- **Визуальный редактор маршрута**: Интуитивное создание точек (Waypoints) кликами на карте, drag-and-drop редактирование.
- **Сценарии поведения**: Настройка действий на каждой точке (взлет, посадка, пауза, разворот, управление оборудованием).
- **Интерактивный интерфейс**:
  - Плавные анимации UI при выборе объектов.
  - Умное масштабирование и кластеризация точек на карте.
  - Адаптивная темная/светлая тема.
- **Валидация в реальном времени**: Проверка корректности высот, дистанций и параметров миссии.
- **Мониторинг**: Отображение телеметрии (заряд батареи, статус подключения, координаты).

## 🛠 Технический стек

Проект реализован как гибридное приложение (Frontend + Backend):

### Frontend (`/frontend`)

- **React 19** + **Vite**: Быстрый и современный UI.
- **TypeScript**: Строгая типизация логики планировщика.
- **TailwindCSS v4**: Адаптивная верстка и темизация.
- **Lucide React**: Иконографика.
- **SVG Engine**: Кастомный движок рендеринга карты (MiniMap) без использования тяжелых GIS-библиотек.

### Backend (`/backend`)

*В разработке / Заготовка*

- **Python**: Основной язык логики взаимодействия с железом.
- **FastAPI**: REST API для команд и WebSocket для потоковой телеметрии.
- **pioneer-sdk**: Официальная библиотека Геоскан для управления дроном.

## 📦 Установка и запуск

### Предварительные требования

- Node.js (v18+)
- Python (3.10+)

### 1. Запуск Frontend (UI)

```bash
cd frontend
npm install
npm run dev
```

Интерфейс будет доступен по адресу: `http://localhost:5173`

### 2. Запуск Backend (Сервер управления)

*Требуется подключение к дрону или симулятору*

```bash
cd backend
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/Mac:
source .venv/bin/activate

pip install -r backend_requirements.txt
py -m uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```
